Wait timeout:
1. global level - in playwirght.config.js file
2. test level - in test 
3. step level - in steps ex: click({timeout:10*1000})

types of timeout:
1. expect (assertion) - expect.configure({timeout:9000})
2. test level = test.setTimeout(6000);
3. step level = click({timeout:10*1000})
4. action timeout = for action attributes
5. navigation timeout = for goto attributes
